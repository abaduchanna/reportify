### Key Changes to Remember

1. **Never commit node_modules/** to GitHub
   - It's already in `.gitignore`
   - It will be downloaded with `npm install`

2. **Never commit Firebase credentials**
   - Store them in .env (also in .gitignore)
   - Share config through secure channel

3. **Don't modify dist/ folder**
   - It's auto-generated by npm run build-win

### Database Rules (Development)

For testing, set rules to allow public access:

```json
{
  "rules": {
    "punches": {
      "$uid": {
        ".read": true,
        ".write": true
      }
    }
  }
}
```

**⚠️ Warning:** This is for development only!

For production, use proper authentication:
```json
{
  "rules": {
    "punches": {
      "$uid": {
        ".read": "auth.uid == $uid",
        ".write": "auth.uid == $uid"
      }
    }
  }
}
```

## Performance Optimization

### Tips for Faster Builds

1. **First build is slower** (downloads dependencies)
   - Subsequent builds: 2-3 minutes
   - First build: 5-10 minutes

2. **Use SSD** if possible (faster file operations)

3. **Close unnecessary apps** (free up RAM)

4. **Check internet speed** (affects npm install)

## Troubleshooting Common Issues

### Issue: "npm: command not found"
**Solution:**
1. Restart Command Prompt
2. Reinstall Node.js
3. Verify PATH environment variable includes Node.js

### Issue: "Cannot find module"
**Solution:**
```bash
# Delete node_modules and reinstall
rmdir /s /q node_modules
npm install
npm run build-win
```

### Issue: Build takes very long
**Solution:**
1. Close other applications
2. Check internet speed
3. Clear npm cache: `npm cache clean --force`

### Issue: "Access Denied" when running batch file
**Solution:**
1. Right-click build.bat
2. Select "Run as Administrator"

### Issue: App starts but UI is blank
**Solution:**
1. Open Dev Tools (Ctrl+Shift+I)
2. Check Console tab for errors
3. Verify Firebase config is valid JSON

### Issue: Punches not saving to Firebase
**Solution:**
1. Verify Employee ID is filled in settings
2. Check Firebase rules allow writes
3. Verify Firebase config is correct
4. Check internet connection
